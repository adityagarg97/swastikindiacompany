# Swastik India Company

Modern React single-page application for Swastik India Company. The interface uses a blue and white theme with red and orange accents and a subtle glassmorphism style.

## Development

```bash
npm install
npm run dev
```

## Testing

```bash
npm test
```

## Build

```bash
npm run build
```

The site can be deployed to GitHub Pages or any static hosting platform.
